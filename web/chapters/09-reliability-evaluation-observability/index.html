9.4 从 0 到 1 搭建 Evaluation System

MMETRICFFAILURE

Evaluation 不是发布前临时跑一次的测试脚本，而是贯穿 Agent 生命周期的研发基础设施。它 ≠ 一个 Judge Prompt ≠ 一张离线准确率表 ≠ 一次 QA。它必须回答三个问题：① 当前版本是否比基线更好？② 在哪些场景变差、为什么？③ 证据是否足够支持发布、回滚或继续实验？

必背

Evaluation is useful only when its result changes an engineering or product decision.

搭建前先写清 Release Decision：允许合并 Prompt 变更？允许切换模型？允许扩大流量？触发人工审查？自动阻断发布？自动回滚？

Release Gate

Evaluation 只有连接到发布决策才形成闭环。决策不止 Pass/Fail：Ship · Canary · Hold · Request Human Review · Rollback。对高风险 Slice：

Overall score improvement cannot compensate for a critical safety regression.

Dashboard ≠ Gate：Dashboard 解释发生了什么变化（Release Comparison · Slice Breakdown · Cost/Latency · Safety · Judge Agreement · Failure Clusters · Regression Cases · Online Drift）；Release Gate 把指标变成显式发布决策。

常见踩坑 ×7

① 等到 1,000 条数据才开始
→ 用少量分层数据先建闭环，再按失败模式扩展。
② 只看总体平均分
→ 看切片、严重程度和回归，不让平均分掩盖高风险失败。
③ 把 LLM Judge 当真值
→ 用人工校准 Judge，监控一致性、偏差和版本漂移。
④ 所有 Bad Case 都加入测试集
→ 去重、归因、标注，分流到 Dev / Regression / Holdout。
⑤ 只评最终答案
→ 同时评 Outcome 和 Trajectory，才能定位工具、规划和恢复问题。
⑥ 只做 Dashboard 不做 Gate
→ 指标必须连接到 Ship / Canary / Hold / Rollback。
⑦ Evaluation ≠ QA

QA 验证确定性软件是否满足规格；Agent Evaluation 测量概率系统在数据分布、轨迹、风险和业务结果上的表现——还需处理 Stochastic outputs · Judge uncertainty · Dataset evolution · Distribution shift · Model/Prompt drift。

项目映射 · 诚信表达

In AutodidactAgent, evaluation was tightly connected to the development loop because each case had an objective numeric target and a case-level score. That gave us a clear signal for whether a synthesized skill actually improved performance and whether the extra development cost was justified.

不要说搭建过完整企业 Evaluation Dashboard / 大规模生产 CI/CD / 全公司 LLM Judge 平台。更准确：I have implemented important evaluation components and objective case-level scoring. For a production platform, I would extend this into versioned datasets, trace storage, calibrated judges, release gates, and an online bad-case flywheel.

90 秒英文答案（完整版见第 11 章 · 答案 08）

I would treat evaluation as lifecycle infrastructure rather than a one-time test before release… The core idea is a data flywheel: every meaningful failure becomes a future regression test.

LAYER 3GENERATION

4. System Layer
