90 秒核心表达

BM25 and dense retrieval are complementary rather than competing approaches. In enterprise RAG, I would combine exact lookup, lexical retrieval, and dense retrieval, apply permission and metadata filters, fuse the candidate lists using RRF or a learned ranker, and rerank the strongest candidates. The final design should be validated on a representative business evaluation set rather than chosen by intuition.

Query Routing：让不同 Query 走最合适的路径 §3.3

WWHENGGATEPPITFALL

Routing 解决的不是“系统支持多少种 Retriever”，而是：当前请求需要什么证据、应该调用哪条数据路径、何时并行、何时澄清、何时停止。

低质量回答

“Exact、BM25、Dense、Graph 和数据库都跑一遍，再看哪个好。”——作为所有请求的默认策略，就没有体现 Query 类型差异、数据源边界、延迟成本预算、权限风险与恢复策略。

Query 类型示例首选路径说明
精确标识符WO-8827391 的进度Exact field / DB lookup主键、工单号、订单号优先做规范化后的确定性查询

特别纠正

编号查询的首选通常不是 BM25，而是 keyword/term query 或数据库精确查询。BM25 可以作为容错召回，但不是主键查询的替代品。

Router 的演进路径 从规则到持续训练

S0确定性解析Regex · identifier parser · schema validation

推荐策略不是“一开始就上最复杂模型”：先统计真实 Query 分布 → 规则覆盖高频低歧义 → 小模型处理可学习边界 → LLM 只接低置信长尾 → 日志建训练集。“规则覆盖 80%”“20 条规则 + 误路由 >10% 再升级”是经验启发，不是通用标准。

WHEN什么时候多路并行反而合理？
① Query 同时含 ID 与自然语言原因；② Router 置信度低且风险允许扩大召回；③ 高召回优先的离线调查；④ 构建评测基线比较路径贡献；⑤ 单一 Retriever 有已知盲区。

但必须设置：并发上限 · 超时预算 · 权限过滤 · 去重融合 · 降级路径 · 成本权衡。
RRF 是候选融合，不是最终相关性证明 → 还需 Cross-Encoder / LLM Reranker → Evidence Validation。
成熟表达

Use the cheapest reliable route first, and expand retrieval only when the query or uncertainty requires it.

项目映射 · 诚信边界

Bakery BI 的 router_agent.py + skill_loader.py 可证明你已有小规模路由实践（意图路由、Skill contract、fallback、数据依赖），但它不是大规模企业检索 Router；AutodidactAgent 的核心是 Case-Based Reasoning Retriever，不应说成完整多路径 Query Router。

映射话术

I have implemented routing at a smaller application level and designed retrieval logic in a case-based agent. I have not yet operated a large production router across SQL, BM25, dense, and graph systems, but I understand how I would evolve and evaluate that architecture.

必背

Query routing is not about choosing the fanciest retriever. It is about selecting the cheapest reliable evidence path for the current request, while preserving a fallback when that decision is uncertain.
