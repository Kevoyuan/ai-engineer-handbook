tenant_id · user_id · resource ACL · memory scope。未经授权的 Memory：不应进入检索候选、不应进入模型上下文、不应在拒答中泄漏其存在。

AutodidactAgent 的诚实定位

AutodidactAgent mainly implements episodic and procedural memory through solved cases and reusable skills. It is not a general-purpose user-profile memory system.

它更接近 Solved Case + Best Skill + Score + Provenance，而不是通用长期用户记忆。

可靠做法不是无限“摘要的摘要”，而是保留事件日志和关键 provenance，从可验证原始记录重新生成 compact view。

必背

I do not treat the transcript as the state. I maintain structured state and compress views while preserving provenance.
