Skills 与路由

100+ SKILLS · CONTRACT · GOVERNANCE
WWHENTTRADE-OFFPPITFALL

当 Skill 超过 100 个，问题不再是“Prompt 怎么写”，而是 Retrieval + Classification + Policy Routing + Governance。把所有 Skill 塞进 Prompt 会带来：Token 成本 · 延迟 · 注意力稀释 · 位置偏差 · 描述冲突 · 未授权能力暴露。Skill 越多，没有治理命中率可能越低。

 when_to_use:
   - The user asks to identify risky
     clauses in a contract.
 when_not_to_use:
   - The user asks for general legal advice.
   - The document is an invoice.

 required_inputs:

 required_permissions: [CONTRACT_READ]
 risk_level: medium
 requires_human_review: true
必背

A skill description should define the decision boundary, not advertise the feature.

命名原则

Verb + Business Object + Optional Constraint
✓ retrieve_invoice_by_id · validate_refund_request · analyze_contract_risk · generate_unit_tests
✗ helper · smart_tool · analysis · process_data

Hard Negatives

除了正例，还要告诉 Router 什么时候绝对不要用、哪些相似 Skill 容易混淆（generate_unit_tests vs generate_integration_tests）。可用于 Prompt examples · Retriever 训练 · Cross-encoder 训练 · 路由评估。

Positive examples improve recall; hard negatives improve boundaries.

REGSkill Registry 与治理
保存：skill_id · version · domain · tags · input/output schema · when_to_use / when_not_to_use · examples · hard negatives · permissions · risk · owner · health · status · cost。
治理重叠：Merge · Deprecate · Rename · Narrow scope · Parameterize · Add negative boundaries。例：generate_daily/weekly/monthly_report → generate_periodic_report(period)。

Prefer parameterized skills over duplicated skills.

EVAL路由评估与失败归因
Candidate Recall@K · Top-1 Routing Accuracy · MRR · No-Match Accuracy · Clarification Accuracy · Multi-Skill Planning Accuracy · Unauthorized Skill Exposure · E2E Task Success · Latency · Cost。
区分失败类型：Retriever / Reranker / Input / Execution / Tool Failure——选对 Skill 但 API 超时，是 Tool Failure，不是 Routing Failure。

MCP 与 Skill：协议层 vs 能力层 补强

WWHYWWHENPPITFALL
MCPSkill
核心标准化暴露/发现工具、资源与上下文封装“如何完成一类任务”的可复用能力契约
关注点连接、Schema、Discovery、Transport适用边界、输入输出、流程、验证、版本
不负责不天然保证业务授权、幂等、事务与任务成功不天然定义跨进程/跨系统通信协议

工程上可以组合成：MCP 负责把能力可靠地“接进来”，Skill 负责描述什么时候以及怎样使用这项能力。

边界

Protocol exposes capabilities; skills encode reusable task procedures. Neither one replaces authorization, validation, or orchestration.
