生产级 PDF RAG

P·R·I·T + C·E
FFAILUREGGATEMMETRIC

“PDF → 抽文本 → 固定长度切分 → 向量库”在真实企业文档上会失败：目录多栏、页眉页脚、复杂表格、流程图、扫描页、盖章签名、跨页引用。结果是阅读顺序错乱、表格行列丢失、标题正文割裂、页眉污染召回、图表信息消失。生产级方案 = 四层处理 + 两条底线。

第一层 · Parsing：先分类，再选解析路径

NATIVE原生文本 PDF
直接读取 text span · font · bounding box · page coordinate · reading order candidate。重点：保留位置和版式信息，为结构恢复提供依据。
SCAN扫描件 PDF
本质是图片容器，需 OCR 输出：识别文本 · bbox · confidence · 页旋转 · 语言。低置信区域不能悄悄入库：重新识别 / 换模型 / 标低质量证据 / 人工复核。
MIXED图文混排 PDF
Layout parser + 图/图表抽取 + Vision-language 理解。输出不应只是“这是一张图”，而应形成可检索语义：“Figure 4 shows an approval workflow: request → manager review → finance review → payment release.”
核心原则

Choose the extraction method by document and page type; do not force every PDF through one parser.

第二层 · Structure Reconstruction：恢复文档语义

 每个信息点携带“定位基因”：
 document_id · page · section_path
 paragraph_id · table_id · figure_id
 bounding_box
  • 多栏阅读顺序：按页面对象顺序抽取会出现“左栏一段 → 右栏一段”交错，必须恢复列、块与正确阅读顺序，并把标题层级附着到正文。
  • 页眉页脚：跨页重复模式识别后删除正文副本，或保留为专门 metadata，避免反复进入 Embedding。
  • 表格：恢复 row / column / header / merged cell / unit / caption / 跨页续表关系，存为 Markdown / CSV / JSON / DB 行，支持精确查询、范围过滤、数值比较、聚合。
  • 图像：绑定 figure number · caption · 周围段落 · page · section · vision 描述。
必背

Structure reconstruction turns page objects into traceable document semantics.

第三层 · Semantic Chunking 与 Hybrid Index

CHUNK结构感知切片规则
同一标题下连续段落 → 一个或多个语义 chunk · 完整条款尽量保持完整 · 完整表格单独结构化 · 图 + caption + 描述绑定为 figure chunk · 超长章节在子标题/段落边界继续切。
权衡：过小 → 缺上下文、检索碎片化；过大 → 召回不精确、上下文成本高。
Contextual Enrichment
孤立 chunk “Revenue decreased by 12%.” → 补充短上下文（来自第 3 章 Currency Risk，描述 2025 财年汇率影响）。原文与模型生成的上下文必须分开存储，避免把生成摘要误当原始证据。
信息类型索引路径
自然语言段落Dense + BM25
合同条款与术语BM25 + Dense
编号、日期、版本Exact / Keyword fields
结构化表格SQL / 结构化存储 + lexical
章节、页码、权限Metadata filter
跨实体关系Optional graph index

   "section_path": ["3 Risk Factors", "3.2 Currency Risk"],
   "content_type": "paragraph", "language": "en", "version": "2026",
   "valid_from": "2026-01-01", "access_scope": "finance-eu" }
核心原则

Do not embed everything in the same way. Index according to the information type and the expected query operation.

必背

The agent decides what evidence it needs; deterministic document tools control how that evidence is retrieved.

错误诊断树：答案错误 → 失败在哪一层？

→ Parsing / ingestion failure

→ Retrieval failure

→ Generation / verification failure

→ Decision-policy failure
必背

A production evaluation should tell us which stage failed, not only that the final answer was wrong.

权限、版本与生命周期

Tenant isolation · Document-level ACL · Page/section 限制 · Version validity · Superseded 文档 · Retention/deletion · Index refresh · Audit trail。权限过滤尽量发生在检索前，返回前再校验一次。版本冲突结合 valid_from/valid_to · supersedes · region · BU · source authority；仍无法确认有效版本 → 明确拒答或升级，而不是随机选一篇相关文档。
