AGENT适合 Agent 的
clarification · planning · creative revision · diagnosis · replanning —— 不确定的决策。
DETERMINISTIC适合确定性服务的
schema validation · prompt assembly · rendering · subtitle generation · permission checks · file conversion —— 可重复的转换。

Use agents for uncertain decisions and deterministic services for repeatable transformations.

IDCharacter Consistency
不能只重复 Character Prompt：Canonical Character Card · Reference Asset Library · Identity Conditioning · Shot-level Consistency Check · Continuity State（Identity · Costume · Object · Spatial · Temporal · Emotion）。
SHOTStoryboard / Shot Spec
结构化：duration · purpose · camera · motion · characters · continuity · transition · constraints。

A good shot is the smallest independently generatable and independently verifiable visual unit.

EVALEvaluator
分层：Script / Storyboard / Visual / Audio / Final Render Validator；组合 Deterministic Rules + Specialized Models + Multimodal Judge + Human Review。输出：status · failure type · evidence · suspected root cause · repair scope · recommended action。

Evaluation should produce repair instructions, not only scores.

ASYNC异步生成与任务状态
Orchestrator → Queue → Worker → Artifact → Event → Resume。状态：QUEUED · RUNNING · SUCCEEDED · FAILED · CANCELLED；前端经 SSE / WebSocket / Polling 接收进度。
Idempotency：生成任务需 idempotency_key——请求超时不代表生成没有开始，重试前先 reconciliation，避免重复计费和重复 Artifact。
COST并行化与成本控制
可并行：independent shots · audio variants · preview。必须串行：continuity-dependent shots · 上游未 lock。

Parallelize independent shots; serialize continuity-dependent shots.

成本：Preview → Validate → Final Render；决策稳定前用低成本模型；复用 Character/Scene Asset；图片动画替代全视频；Retry 上限；项目预算。

Generate cheaply until creative decisions stabilize.

Multi-Agent：拆在 Operational Boundary，而不是 Persona Boundary

WWHENTTRADE-OFF
USE值得拆
权限边界不同 · 工具/运行环境不同 · 子任务可独立评估 · 有真实并行收益 · 需要独立 Critique · 不同模型/成本策略 · 高风险隔离。
AVOID不值得拆
仅因为“研究员/经理/评论家”听起来高级；所有 Agent 共享同一状态和工具；没有独立验收；通信开销高于专业化收益。
原则

I split agents at operational boundaries, not personality boundaries.
