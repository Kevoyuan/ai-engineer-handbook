Q24 · 梯度下降调低 Loss，为什么线上却变差？

Gradient Descent 更新 θ ← θ − η∇L。η 控制步长；训练目标与客户效用并非同一量。核对训练曲线、有效数据、独立验证集、下周未见客户切片。

Q25 · Bias/Variance 与数据泄漏怎么区分？

症状证据处理
训练与验证都差欠拟合 / 数据或目标不正确核对数据与容量
训练好验证差过拟合、漂移、泄漏都可能先按时间/实体检查拆分
未来统计被用于预处理真正的数据泄漏先切分再 Fit

Q26 · Entropy、Cross Entropy、KL、Perplexity 有何区别？

Entropy H(p) = - Σ p log p
CrossEntropy H(p,q) = - Σ p log q
KL(p||q) = H(p,q) - H(p)
Perplexity = exp(mean token NLL) [natural logs]
可验证的边界

KL 不对称；Perplexity 只有在 tokenizer/样本/归约一致时才适宜比较。Loss 减少不等于 RAG Faithfulness 提升。

Q27 · MLP、Activation、Loss、BatchNorm / LayerNorm 的约束是什么？

Linear 后接非线性才能表达复杂非线性；PyTorch CrossEntropyLoss 接 raw logits；BCEWithLogitsLoss 通过稳定的 log-sum-exp 组合处理二分类；BatchNorm 与 LayerNorm 的统计轴不同。

Q28 · LoRA / Self-training 能保证不会遗忘吗？

不能。要在旧任务、新任务及高风险权限切片上对比；伪标签会自我强化错误，封存 holdout 与人类抽检不能跳过。

Q29 · Convex 优化与 Vision 任务为什么不能混在一起谈？

一般深度网络的非凸目标无通用全局最优保证。Classification、Detection、Segmentation 的标注粒度与指标不同；OCR 表格抽取不能只报图片分类准确率。
