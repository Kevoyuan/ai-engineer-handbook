Agent Experience Learning：经验要经过 Promotion Gate §9.X

Agent 自我学习不是“任务结束后自动改权重”。Raw Trace 先经过 Eval、Root Cause、Distillation 和 Validation，再决定它应该进入 Memory、Skill、Deterministic Rule、Regression Dataset 还是 Training Dataset。

FIG.9.X1 · EXPERIENCE PROMOTION SYSTEM

把“发生过”变成“以后可以安全复用”

Trace 是证据，Experience 是经过验证的抽象；不同经验应该晋升到不同系统层。

01

Production Trace

记录 observable action、structured decision、Tool I/O、state transition、validation、cost 和 outcome；Raw success log 不是 ground truth demonstration。
02

Eval + Root Cause

先判断是 Agent、Tool、Data、Permission、Environment 还是 Evaluator 的问题，再决定有没有可复用 lesson。
03

Experience Distillation

抽取 trigger、recommended action、anti-pattern、applicability、evidence、scope、version compatibility 和 do-not-apply 条件。
04

Promotion Router

根据稳定性、作用域、权限、是否可程序化、是否可评测，选择 Memory / Skill / Rule / Regression / Training。
05

Eval / Shadow / Release

经验从 CANDIDATE → VALIDATED → SHADOW → ACTIVE；任何 promotion 都需要版本、证据、回滚路径和 regression protection。
核心原则

Agent self-learning is a controlled experience-promotion system, not an uncontrolled self-modification loop.

FIG.9.X2 · WHERE SHOULD EXPERIENCE LIVE?

不是所有经验都应该进 Memory，更不是所有 Memory 都应该进权重

经验类型 推荐落点 为什么
用户 / 项目临时约束Profile / Project Memory需要 scope、失效与可删除性
重复出现的成熟任务方法Skill / Procedure把多个 Case 抽象成可复用步骤
必须满足的业务不变量Code / Policy / Validator不应该依赖模型“记得”
真实生产失败Regression Dataset学习必须变成可重复验证
稳定、重复、参数层行为缺口Training Dataset只有有明确 Eval Contract 才进入 SFT / preference / RL
FAST外置经验快路径
Memory / Skill / Rule / Regression：可追溯、可失效、更新快。
SLOW参数学习慢路径
Curated Training Data → SFT / preference / RL → full regression → model release。
NEGATIVE TRANSFER

经验系统不能只测“召回后变好多少”，还要测被召回或晋升的经验是否让原本正确的任务变差。Stale lesson、scope leakage 和 self-reinforcing error 都属于必须监控的学习风险。

最终原则

Learning is incomplete until the lesson becomes testable.
