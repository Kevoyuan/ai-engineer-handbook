TRACE CONTEXT PATTERNS

Capstone 里 get_current_run_tree() 有三种典型用途：① capture 当前 Run ID，后续绑定 Feedback；②写入 ls_provider / ls_model_name，让模型 Usage 能解析为成本；③为非 LLM Tool Run 直接写 usage_metadata.total_cost。它们对应三个通用模式：Correlation、Cost Resolution、Literal Tool Cost。

CANONICAL RULE

Tags classify, metadata slices, feedback judges. 即使这些字段都能被 Filter，也不要混淆它们的语义。

COST ATTRIBUTION

Attribution first → aggregation second → optimization third. 来源中数据库查询的 $0.0007 是 Capstone 人工注入的模拟成本，不是通用数据库价格；它的真正意义是演示 Child Tool Run 也应贡献可归因成本。

SIGNAL PROVENANCE

Thread-level satisfaction evaluator 与 thumbs-up/down feedback 是不同证据来源。即使都使用 0/1，也应保留 signal_source 和 evaluator/version metadata。来源材料要求比较二者是否完全一致，但给定文本没有提供该 Quiz 的答案，因此手册不记录具体结论。
