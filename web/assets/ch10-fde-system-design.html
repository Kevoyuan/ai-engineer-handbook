Q10 · Private Link、BYOC、On-prem 有什么本质区别？

模式主要约束容易误判
SaaS厂商运营计算及数据平面隔离不等于专属物理环境
Private Link部分网络链路使用私网地址不等于服务搬到客户 VPC
BYOC / VPC指定组件运行在客户云账号运维/遥测出口仍需审查
Air-gap无实时外部连接（按合同定义）云模型 API 不可直接假设可用
工程边界

部署选择的首要证据是一份完整的数据流和 Egress 表，而不是一句“我们支持 Private Link”。

Q11 · 有 Retry 了为什么还要 Circuit Breaker？

重试仍消耗下游资源；Breaker 在依赖持续失败时拒绝新尝试，配合并发上限和有界队列。退避必须有总 deadline、次数预算和 jitter；故障写入先确认幂等。

trusted host → operation safety classification
→ retry budget / deadline → concurrency admission
→ downstream call ├ success
                 ├ transient → bounded jitter retry
                 ├ repeated fault → circuit OPEN / degrade
                 └ unknown write → reconcile

Q12 · 支付 Tool 超时是否表示首次操作没成功？

不。超时只表示调用方不知道提交结果。必须用持久化业务 operation ID、批准权限、下游可验证的幂等契约；结果未知时查询状态或对账，不能盲目生成新 key。

Q13 · Ontology、Knowledge Graph、GraphRAG 是一回事吗？

对象负责什么
Ontology / Semantic layer实体、动作、业务规则、单位与指标定义
Knowledge Graph显式关系与事实存储/遍历
GraphRAG利用关系进行证据检索与上下文构造
Databricks Metric View集中维护可查询的 Fields 和 Measures

例如“迟到交付率”的分子、分母和时区必须由业务确认。Metric View 可复用指标，却不会自动定义订单动作权限或完整 Ontology。

Q14 · SLI、SLO、Error Budget 怎么用于 AI Agent？

SLI = authorized, grounded, reviewed results within 8s
      / all eligible investigation requests
SLO = 99.0% over 28 days (hypothetical target)
Example: 10,000 eligible tasks → budget 100 misses
Security leaks: critical blocker, never normalized into budget

明确哪些算 eligible，拒判和超时怎么计数，并把 p95、源数据时效性、越权事件分别作为独立 SLI；上述数字不是产品默认值。

Q15 · 为什么 Cost per Successful Task 比 Token 单价重要？

cost / approved success = (model + retrieval + tools + infra
                      + retries + included human review)
                       / human-approved correct tasks

便宜模型如果带来更多重试和人工修复，整体成功任务成本可能更高。按同一用户群和错误风险分层比较，不把越权或错误解释当作成功。

Q16 · Walking Skeleton 到底证明了什么？

证明一条最小真实路径能够跨过 SSO、数据授权、部署、Trace 和验收关口。它不证明吞吐、稳定性或企业安全认证；模拟身份的本地 Notebook 也不等于部署成功。
