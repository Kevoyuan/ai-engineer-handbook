四轮 12 分钟模拟面试

A · RAG 撤权时差

Tenant A/B 均有订单 42；向量检索返回后、读取原文前，员工访问权限被撤销。请画可信身份、Exact SQL、向量索引、Cache 与二次授权的调用时序。

验收标准：通过：未授权候选/段落不进入 Context、Trace 或 Cache；分别量化内容新鲜度与撤权到拒绝的延迟。

B · CDC 时序和特征泄漏

Carrier 记录乱序、重复和删除；某特征事件时间 11:00 但 13:00 才到达，预测发生在 12:00。设计 Source Sequence、SCD2、回放与 As-of Join。

验收标准：通过：12:00 预测不得读取 13:00 才可用的特征，且快照+CDC 不重复计数。

C · 支付超时与重试风暴

退款 Tool 在后端提交后响应超时；Carrier API 又连续 503。设计人审、Operation ID、对账、退避/熔断、队列上限及未知结果状态。

验收标准：通过：绝不以新 Key 盲重试；工具授权和副作用有单独审计，重试放大可测且有上限。

D · Pilot 漂移与现场故障

Pilot 平均准确 95%，生产复核仅 70%，一个关键权限切片退化；演示现场依赖服务 503。给出 Golden Set、Release Gate、Canary、真实告知与 Rollback。

验收标准：通过：安全 Slice 失败阻断发布，明确分母和人工裁决，降级样例显著标注而不伪装实时结果。
