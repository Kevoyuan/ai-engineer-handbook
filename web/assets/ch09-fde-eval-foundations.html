模型“99% 准确”并不代表高风险任务可靠。这里先建立错误矩阵和概率约束，再讨论抽样与在线实验。

Q30 · 99% Accuracy 能否漏掉全部安全风险？

990 legitimate + 10 violation requests
Predict ALL as legitimate
Accuracy = 990 / 1000 = 99%
Violation Recall = 0 / 10 = 0%

针对违规风险，至少单独报告 Precision、Recall、F1、混淆矩阵与 FN 负担，不能用宏观均值掩盖关键 slice。

Q31 · 说 0.9 Confidence 就代表 90% 正确吗？

只有经独立数据校准的概率才支持类似解释。Reliability Diagram、Brier/Log Loss 和分桶标注有价值；Brier 同时受分辨能力影响，分数低不能单独证明校准更好。

Q32 · LLM 自己生成题与答案，可以做 Golden Set 吗？

可做压力样本，但必须绑定来源证据和独立审定，不能把自生成标签当作正确事实。开发集、压力集、密封 holdout 必须隔离。

Q33 · Bandit 与 A/B 测试该怎么选？

方法适用场景风险边界
固定 A/B可解释的实验对照明确分流与评估时窗
Bandit低风险、可重复试验、快速反馈偏差与自适应曝光
Shadow / Canary未曝光对照 / 安全分阶段上线不能绕过安全门禁
