Multi-Agent Conflict Control：冲突要进 Control Plane §8.R

生产级 Multi-Agent 不追求“Agent 永远不冲突”，而是把冲突分类成 authority、quality、resource 三类，并分别用权限、证据、状态机与并发控制解决。

多数票边界

Three votes are not three independent observations. Count independent evidence before counting Agent opinions.

FIG.8.R2 · MULTI-AGENT HARNESS CONTROL

Evidence → Authority → State Transition → Recovery

意见可以来自模型，但真正的执行权、状态转换和共享资源修改必须由 Harness 明确控制。

01

Finding / Artifact

Worker / Specialist 返回结论，但同时携带 evidence、uncertainty、artifact version 与 blocking risk。
02

Verifier

优先用 test / command / structured check；模型 Judge 只在需要语境判断时进入，并输出 PASS / FAIL / PARTIAL + evidence。
03

Authority Gate

Lead 可拥有 orchestration authority，但 truth authority 来自 evidence；高风险、越权或超 Scope 决策进入 Policy / Human Gate。
04

State / Concurrency Gate

Task DAG、owner、revision / CAS、write-scope warning、workspace isolation 与 merge gate 约束共享状态修改。
05

Repair / Escalate / Complete

Repair Loop 必须有 attempt budget；超过预算、证据不足或权限不够时显式 ESCALATE，而不是无限 Reviewer ↔ Worker 循环。
DEEPSEEK HARNESS

当前实验性 Agent Teams 一手资料支持 shared task DAG、monotonic revision + CAS、Lead-only teammate lifecycle 与 write-scope overlap warning；但 writeScopes 明确只是 advisory，不是 lock，而且默认共享 checkout，不会自动创建 Git worktree。

最终原则

A reliable Multi-Agent system is not one where Agents rarely disagree; it is one where disagreement has a deterministic resolution path.

FIG.8.R3 · FOUR-LAYER CONSISTENCY MODEL

一致性不是 Agent 观点相同，而是四层都有明确提交语义

Communication topology 可以灵活，但 State、Execution、Artifact、Decision 的 authoritative path 必须可检查、可拒绝 stale/duplicate、可审计。

STATE CONSISTENCY

One authoritative commit path

authoritative store · versioned snapshot · revision/CAS · single writer / transaction / workflow engine。重点是 local view 不等于 committed state。
EXECUTION CONSISTENCY

Duplicate delivery must not mean duplicate effect

task id · lease · dedupe · idempotency · reconciliation。Lock 解决 mutual exclusion；幂等解决重复业务副作用，两者不能混为一谈。
ARTIFACT CONSISTENCY

Candidate → Validate → Commit

schema · provenance · lineage · integrity · acceptance。并行结果先 normalize / conflict-detect / validate，再产生 committed artifact，而不是直接 concat。
DECISION CONSISTENCY

Evidence + Authority + Policy

允许合理分歧存在；deterministic verifier、contextual judge、authority matrix、policy 与 human escalation 决定 committed action。

Communication may be flexible; commit semantics must be explicit.
