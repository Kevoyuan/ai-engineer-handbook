Grounded Document Agent：从 PDF 检索到可验证证据链 §5.Y

长文档问答的目标不只是找到相似文本，而是让每个回答都能沿着 Evidence Chunk → Page / Section → Source Document 反向追溯。公开项目示例使用 LlamaParse 解析长 PDF，并让本地 Ollama 模型完成检索与回答，同时返回精确页面引用；生产系统应在这个基础上继续补齐证据充分性判断、引用校验与拒答边界。

FIG.5.Y

Grounded Document Agent = provenance-preserving retrieval + support gate + citation verification

解析质量决定检索上限；Grounding 质量取决于答案是否被原始证据真正支持，而不是页面上是否出现了一个 citation 字符串。

1 · PARSE

结构化解析，而不是只抽纯文本

尽量保留 page boundary、heading hierarchy、table、figure、reading order 与可定位的 layout metadata。
2 · INDEX

Chunk 不能切断 provenance

每个 EvidenceChunk 至少携带 document_id、page、section、chunk_id 与 parser provenance；布局敏感任务再保留 bbox / element metadata。
3 · RETRIEVE

检索 Evidence Bundle，而不是孤立相似片段

查询可组合 semantic retrieval、keyword / metadata filter、reranking，并在需要时读取相邻页或同一 section 的连续上下文。
4 · SUPPORT GATE

先判断证据够不够，再决定是否回答

不足时应扩展检索、重写 query、检查相邻 section，或者直接 abstain；不要把“检索到了东西”误当成“足够支持答案”。
5 · ANSWER

只基于当前 Evidence Bundle 生成

回答中的关键 claim 应映射回一个或多个 source span，并携带 page / section citation。
6 · VERIFY

验证 claim ↔ evidence，而不是只验证 citation 存在

Citation Presence 只是第一层；更重要的是 Citation Correctness 与 Claim–Evidence Entailment。失败时修复回答、重新检索或拒答。
GROUNDING CONTRACT

Citation Presence ≠ Citation Correctness。页面号存在，只能证明系统打印了引用；真正的可靠性要求引用页面支持对应 claim，并且用户能够回到原文验证。

PARSING CEILING

Document QA quality ≈ Parsing × Retrieval × Evidence Selection × Generation × Citation Verification。解析阶段把表格、阅读顺序或页边界破坏之后，后面的 embedding 与 LLM 很难恢复原始语义。

EvidenceChunk：把 provenance 当成一等数据

Field为什么需要生产用途
document_id区分来源与版本权限、去重、更新与 lineage
page / section保留人类可验证的位置页面引用、邻页扩展与 section-aware retrieval
chunk_id为证据建立稳定标识缓存、评估、回放与错误分析
bbox / element保留视觉文档的局部位置表格、图像、highlight 与 multimodal verification
parser_provenance知道文本是如何被解析出来的parser regression、版本比较与重建索引
retrieval_score记录为何进入 Evidence Bundlethreshold、reranking、eval 与 failure analysis
AGENTIC BOUNDARY

普通 RAG 可以是一次 retrieve → generate；Agentic Document QA 的价值从“检索变成决策过程”开始：系统根据当前证据决定继续检索、扩大范围、查看相邻页面、重写查询或拒答。这个循环应保持 bounded，并把停止条件、最大检索轮数和权限边界写清楚。

FAIL常见错误：把 citation 当装饰
只检查“有没有 [Page 17]”会放过错误引用。更可靠的评估单位是 claim：每个关键 claim 是否有匹配 evidence，evidence 是否真的蕴含该 claim。
GATE正确边界：证据不足时允许不回答
Grounded system 的目标不是最大化 answer rate，而是最大化 supported answer rate。证据不足时 abstain，是可靠性机制，不是失败。
