Q38 · 有环的 Agent DAG 可以直接执行吗？

identity → authorize → read → explain
                       ↘ review → write

Kahn's topological sort: O(V + E)
If output count != vertex count → cycle detected.

依赖图有环就不能拓扑排序；在任何副作用之前先拒绝。动态 ReAct 循环可以合理地重复工具调用，但需要预算/停止策略，不属于固定 DAG 的循环。

Q39 · Mock 通过就证明 Agent 没有越权吗？

不。依赖注入让 Policy 和 Reader 可替换，测试未授权时调用数必须是 0；真正的身份验证和存储 RLS 仍需独立集成验证。

可验证的边界

区别“验证调用顺序”与“验证资源授权”：Fake 只能证明代码路径在测试输入下满足预期，不能替代生产 Resource Policy。
