Q34 · Top-K 为什么不能把所有结果先排序？

小 K 场景堆选择为 O(N log K)，额外空间可做到 O(K)；排序一般 O(N log N)。但可访问集合必须先过滤，堆排序不能找回上游 ANN 漏掉的候选。

Q35 · CSV 为什么不能直接 split(',')？

引号内可包含逗号或换行，应该使用 CSV Parser 并严格校验 Header、Tenant、时区、重复 ID 和 enum。不合法源数据进入 quarantine，而不是静默丢弃。

Q36 · Sliding Window 如何计算近 15 分钟错误？

already-sorted event times
→ deque append
→ evict timestamp < current_time - 15 minutes
→ maintain eligible request count + failure count

简单双指针在有序事件上为摊还 O(N)，但无序事件必须声明 Watermark / 重排策略；这是两种完全不同的数据契约。

Q37 · GIL 让 Python 线程完全不能并行吗？

标准 CPython 的 GIL 限制 Python 字节码多核 CPU 并行；线程仍适合 I/O 重叠，进程适合重 CPU。Python 3.13+ 有可选 free-threaded 构建；是否真正关掉 GIL 和扩展兼容性都要核查。
