Q59 · Inference-Time Compute / Scaling Laws

更多验证调用或搜索深度可能提高部分任务质量，但会增加成本与延迟。预训练 Scaling Laws 不保证任意追加推理 Token 都有效。

失败/验收： 比较同一 Holdout 的正确成功任务率、p95、总成本，设置停止预算。

Q60 · Multimodal VLM / Speech / Diffusion

VLM 判断图片/文本；ASR 是音频到文字；TTS 是文字到音频；Diffusion 是迭代生成机制。它们的标注、性能与隐私指标不同。

失败/验收： 扫描票据测试字段 Exact Match；语音测试错听数字与取消延迟。

Q61 · Constitutional AI / RLAIF

AI 反馈可以帮助构造训练偏好，但模型自评不授予生产 Tool 权限，也不替代人工和外部安全策略。

失败/验收： 让 AI Judge 偏爱越权操作，Host 仍应阻断，独立审查偏好偏差。

Q62 · Differential Privacy / Federated Learning / Interpretability

DP 需要明确 ε/δ、剪裁、噪声和 accountant；Federated Learning 只说明数据在本地训练，不保证更新没有泄漏；可解释性分析不等于隐私证明。

失败/验收： 核对 FL 安全聚合，追踪 DP 预算组合，区分解释结果与身份策略。
