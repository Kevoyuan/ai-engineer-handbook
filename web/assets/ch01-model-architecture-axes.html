模型架构的八个术语：其实横跨多个分类轴 §1.22

先区分底层网络结构、训练与推理目标、模态、模型规模和 Agent 系统拓扑。八个术语不是互斥的八种基础模型。

PatternAxisBoundary
GPTDecoder-only / autoregressiveEncoder–decoder can generate too
MoESparse expert activationTotal parameters ≠ active compute
LRMReasoning-oriented training/inferenceNot a fixed neural architecture
VLMImage + language modalityVerify OCR and visual grounding
SLMSize and deployment constraintsQuantization is an independent technique
LAMTool/action behaviorTool call ≠ execution or permission
HLMHierarchical agent controlPlanner/executor often describes orchestration
LCMResearch: concept-level modelingMeta predicts SONAR sentence embeddings, not knowledge graphs

例如 MoE、VLM 和 reasoning model 可以同时描述同一系统。Meta 的 LCM 是句子表示空间中的概念级预测研究，而不是知识图谱检索架构。

Core rule

Model structure, training, modality, scale and system control are orthogonal design axes.
