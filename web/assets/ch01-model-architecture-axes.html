模型架构的八个术语：其实横跨多个分类轴 §1.22

先区分底层网络结构、训练与推理目标、模态、模型规模和 Agent 系统拓扑。八个术语不是互斥的八种基础模型。

术语分类轴工程边界
GPT仅解码器／自回归编码器–解码器同样可以生成文本
MoE稀疏专家激活总参数量不等于激活计算量
LRM推理导向训练与推理不是固定的神经网络架构
VLM图像与语言模态需要检验 OCR 和视觉证据定位
SLM规模与部署约束量化属于独立优化技术
LAM工具与行动行为Tool Call 不等于执行或授权
HLM分层 Agent 控制规划／执行器通常描述编排模式
LCM研究：概念级建模Meta 预测 SONAR 句子向量，而不是知识图谱

例如 MoE、VLM 和 reasoning model 可以同时描述同一系统。Meta 的 LCM 是句子表示空间中的概念级预测研究，而不是知识图谱检索架构。

核心规则

Model structure, training, modality, scale and system control are orthogonal design axes.
