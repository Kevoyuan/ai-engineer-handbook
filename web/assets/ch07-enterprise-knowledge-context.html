Enterprise Knowledge Context：企业知识是受治理的上下文 §7.K

企业知识基础设施的目标不是把更多文本塞进向量库，而是把组织概念、规则、流程、案例和实时事实变成可版本化、可授权、可追溯的 Agent Context。

FIG.7.K1 · KNOWLEDGE CONTEXT LIFECYCLE

Source → Organize → Process → Serve → Govern → Agent Context

SOURCE

文档 · 流程 · 规则 · 案例 · 数据

provenance · owner · raw version
ORGANIZE / PROCESS

classify · relate · index · structure

不是所有内容都向量化；保留层级、关系、适用范围和事实结构。
SERVE

RAG · API · Structured Query · File Search

按数据形状、时效、权限和失败语义选择供给方式。
GOVERN

version · permission · validity · correction

owner · expiry · supersede · lineage · usage feedback
CONTEXT

可解释、可验证、可授权的任务上下文

Agent 使用的是经过治理的 evidence，不是无来源文本堆积。
核心原则

Enterprise knowledge is governed context, not merely retrieved text.
