Graph Query Governance：Graph Retrieval 不等于自由执行 Cypher §2.G

生产图检索的关键是把 LLM 提议与实际查询执行分开：模型表达想找的关系，可信系统决定能查什么、查多深、查多久、能返回哪些数据。

FIG.2.G1 · GOVERNED GRAPH QUERY

可信身份 → 受控查询 → 有界图证据

这是一条权限和资源预算控制路径，不是模型对任意 Cypher 的自然语言承诺。

MODEL PROPOSES

Intent / Relationship Request

例如：哪些服务通过 DEPENDS_ON 关联到当前项目？模型不可直接改写 tenant_id。
↓
01 · TRUST

Tenant / Actor / ACL

可信认证上下文，非 Prompt 指定。
02 · SHAPE

Approved Cypher Template

受审核的关系类型、属性、参数与 procedure allowlist。
03 · BUDGET

Hops / Fan-out / Timeout

限制遍历、行数、时延、结果体积与并发。
↓
DATABASE ENFORCES

Least-Privilege Graph Principal

数据库角色必须真实限制可读数据与可执行操作；Driver 的 read-routing 不是权限保证。
↓
EVIDENCE ONLY

Bounded Rows + Provenance / Version

返回授权范围内的有界证据；查询命中不能自动授权实际业务动作。
工程边界

The model proposes query intent; the trusted runtime owns query shape, access scope and resource budget.
