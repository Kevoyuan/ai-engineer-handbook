Q40 · Vector Databases

向量索引用 ANN 找语义近邻，但精确订单号必须 SQL/Exact。向量近邻分数不能充当权限或事实证明。

失败/验收： 另一租户的高相似文档不能进入 reranker 或上下文。

Q41 · Embedding Versions and Drift

文档编码器、Query 编码器、Chunker 和距离度量必须版本一致。同维向量不一定共享语义空间。

失败/验收： Shadow index 对比授权 Recall@k，回滚时同时切换编码器与索引。

Q42 · Index Freshness and Staleness Windows

区分 Source Commit、CDC、Embedding、Index Visible 与 Cache Invalidated。撤销权限和内容新鲜度是不同 SLI。

失败/验收： 检索后、获取段落前撤权：必须 Fail Closed 或重新验证源权限。

Q43 · ColBERT Late Interaction

ColBERT 让 Query 与 Document 的 Token 表示在后段按 MaxSim 交互，保留细粒度匹配，但索引/计算比单向量方案更复杂。

失败/验收： 只在术语/关系召回困难时测试增益；比较 index 大小、nDCG 与查询 p95。
