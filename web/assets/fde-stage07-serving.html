Q48 · Rate Limiting / REST APIs

可信 Tenant 身份驱动 Token Bucket 与并发预算。REST 写接口使用稳定操作 ID，429/503 不能触发无限重试。

失败/验收： A 租户耗尽配额不能阻止 B 租户使用独立配额。

Q49 · Consistency / CAP

不同状态需要不同保证：权限和最终写入须可核验；CDC/索引可以在声明范围内延迟但必须暴露新鲜度。CAP 是分区故障下的取舍。

失败/验收： 付款已提交却丢失响应：不能盲目发起第二次付款。

Q50 · Model Versioning / Registry Promotion

UC Model Registry 的 Champion alias 指向版本，不保证在线端点已切换。需要端点配置校验、Golden Eval、Canary 和回滚。

失败/验收： Tag 看似 Production，但端点仍在服务旧版本。

Q51 · Enterprise Model Selection

比较安全边界、业务正确率、证据忠实、端到端 p95、成本/成功任务；规则、SQL、小模型与强 LLM 都有合理位置。

失败/验收： 只比较 Token 价格忽略重试、人审和数据驻留。

Q52 · Quantization / PagedAttention / MoE

量化改变数值精度；PagedAttention 改 KV 分块；MoE 只激活部分专家。三者作用不同，必须按具体 GPU/框架基准测试。

失败/验收： 比较 VRAM、TTFT、p95、输出质量，不把总参数量当单次计算量。

Q53 · Speculative Decoding

Draft 小模型候选必须经 Target 验证；正确的无损接受算法保留目标分布，但不保证每次随机输出字面相同。

失败/验收： 拒绝率高可能反而变慢；观察吞吐与并发条件。

来源与边界 / Source ↗

Q54 · AI Governance / SOC2 / EU AI Act

SOC 2 是限定系统/期间的审计报告，不能代替 AI Act 的用例/角色/风险分类。法规日期需参考修订后官方资料。

失败/验收： 客户声称“有 SOC2 所以所有 AI 自动合法”：需要完整责任矩阵与证据。

来源与边界 / Source ↗

Q55 · Enterprise SSO SAML / OIDC

验证 OIDC iss、aud、签名、exp；身份认证不授予订单行级权限。SAML 与 OIDC 的协议形态不同，最终都必须映射可信租户策略。

失败/验收： 错误 Audience、撤权后会话、模型自带 tenant_id 均应拒绝。

来源与边界 / Source ↗

Q63 · Distributed Training FSDP

PyTorch FSDP2 分片权重/梯度/优化器状态，通信成本与模型大小有关。分布式训练不等于推理显存优化。

失败/验收： 检查 All-Gather、Checkpoint、world size 和 OOM，而不是只看吞吐。

Q64 · Palantir Foundry / AIP / Apollo / Gotham

官方三大集成平台为 Foundry 数据/Ontology、AIP Agent/AI、Apollo 交付；Gotham 属领域化应用，不能混作同一层。

失败/验收： 不要把 GraphRAG 当 Ontology，也不要假设 Databricks 组件与 Palantir API 兼容。
