Long-Running Multi-Agent Handoff：接力必须先验证再提交 §8.S

长周期 Multi-Agent 的关键不是让每个 Agent 自己记住做到哪，而是让 Agent 可以随时消失，而 Workflow State、已验证 Artifact 和合法状态转移仍然持续存在。

FIG.8.S1 · DURABLE HANDOFF PROTOCOL

Candidate ≠ Committed Artifact；Agent 说 done ≠ Workflow 已推进

01 · READ

Committed State + Versioned Inputs

Worker 读取 durable workflow state、revision、owner/lease 与已经提交的 input artifact，不直接把上一 Agent 的自由文本当作事实。
02 · PRODUCE

Candidate Artifact

Agent 在 bounded task 内工作，输出 typed candidate artifact；此时它还不能让下游开始。
03 · VALIDATE

Schema → Semantic → Integrity → Acceptance

先检查结构可解析，再检查业务 invariant，再确认引用的文件/证据真实存在，必要时验证实际任务目标是否达成。
04 · COMMIT

Artifact Commit + Atomic State Transition

验证通过后把 Artifact 标为 authoritative，并用 CAS、single writer、transaction 或 workflow engine 提交合法 transition。
05 · PUBLISH

Next Task Becomes Runnable

只有 committed state 才发布给下游；失败则 repair、retry 或 escalate，不让 invalid candidate 静默传播。
核心顺序

produce → validate → commit → publish downstream

FIG.8.S2 · STATE SEPARATION

不要把 Workflow State、Artifact 和 Agent Context 混进一个 Conversation

WORKFLOW STATE

Where execution is now

stage · status · revision · owner · lease · retry · approval · next transitions
ARTIFACT STORE

What work actually exists

artifact_id · version · lineage · checksum · schema · validation_status · storage_uri
AGENT CONTEXT

What this worker needs now

prompt · retrieved context · tool results · scratch state · local plan
恢复边界

Agent 进程崩溃不应让 Workflow State 或已验证 Artifact 一起消失。恢复依赖 durable state / checkpoint / event history，而不是模型“记得上次做到哪”。

不是所有失败都叫“回滚 checkpoint”

FIG.8.S4 · LONG-RUNNING OPERATIONS

跨小时/跨天还要解决 Lease、版本兼容与 Handoff Metrics

LEASE

Who owns the task now?

owner · lease_token · heartbeat · expires_at · reassignment
VERSIONING

Can old state run on new code?

workflow_version · schema_version · prompt/tool/policy version · migration / pinning
METRICS

Is the handoff reliable?

handoff failure · resume success · stale-write reject · duplicate side effect · time in stage
总原则

Agents may be ephemeral; workflow state and validated artifacts must be durable.
