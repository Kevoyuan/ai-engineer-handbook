Context 成本评估：95% 工具输出压缩不等于 95% 总成本下降 §9.24

区分压缩率、Provider 计费 Token、端到端任务成本和经验证的 Task Success；失败任务的成本也要进入分子。

Tool reduction = 1 - compressed_tool_tokens / raw_tool_tokens
LLM bill = uncached_input * rate + cached_input * cached_rate
         + output * output_rate + other charges
Full task cost = LLM bill + tool/API + retrieval/index + review + retries
Cost / success = cost of ALL task attempts / verified successful tasks

计算示例（不是厂商实测）：工具输出占输入 40%，仅该部分缩减 95%，则总输入最多缩减约 38%，仍未计入输出 Token 与其他账单。
