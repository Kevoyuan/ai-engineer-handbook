REFERENCE ARCHITECTURE · 00.2

Production AI Agent 参考架构

这是对一次受控 Agent Runtime 的放大图。它把 Context 构建、Model 推理、Capability 执行、Host 侧 Policy、Validation 与 Production Control Plane 分开，避免把 LLM 本身误认为完整 Agent 系统。

ENTRYUser / Application → Request / Identity / Session在推理开始前先确定 current goal、tenant、role、permission、risk level 与 task/session boundary。
CONTEXT PLANE · CH 02–07Context Builder只组装当前一步真正需要的上下文：system instructions、conversation / working state、long-term memory、retrieved evidence 与 available capabilities。

CONTROL PLANE · CH 09Trace · Eval · Safety · Cost · Latency · Release · MonitoringControl Plane 负责测量和治理 Runtime，而不是替代 Runtime 本身；它为 release、rollback、diagnosis 与 cost-per-successful-task 提供证据。
