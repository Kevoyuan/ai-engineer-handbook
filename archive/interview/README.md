# Interview Archive

This directory preserves interview-specific material without letting it define the core handbook structure.

Keep here:

- company-specific interview question banks
- 90-second answer scripts
- high-frequency follow-up questions
- memorization frameworks
- interview checklists
- historical interview-oriented versions of the handbook

The reusable engineering principle behind any useful interview question should be promoted into the core handbook first. The interview version may then reference or summarize that knowledge for recall.
