# Complete handbook design preview

A standalone redesign covering all 9 chapters, 26 registered supplementary diagrams, 87 searchable sections, the chapter directory, saved chapters, and a knowledge map. The reader includes direct section links, previous/next navigation, text-size controls and focus reading. Chinese/English and light/neutral-charcoal dark themes are persisted locally.

Run `npm install`, `npm run build`, then `npx vite preview --host 0.0.0.0 --port 4180`. The complete preview runs independently of the original content server. The production artifact is `web/site/`. Run `npm run publish:web` after source changes and commit the generated artifact with its source; Vercel serves this directory without a remote build. Original `web/chapters` and `web/assets` remain the content-generation inputs.

`npm run sync-content` derives every chapter, its registered supplements, bilingual text, and the section search index from `../../web`. Python 3 with BeautifulSoup (`python3 -m pip install -r scripts/requirements.txt`) and the installed Node tooling are required for content regeneration, not runtime viewing. Browser tests use the project Playwright dependency; install its browser with `npx playwright install chromium` when needed. Generated chapter files live in `public/content`. No technical chapter is abbreviated to fit the design.

The installed Better Design component library and Iconoir icons remain the shared UI owners. Runtime composition and semantic theme tokens are in `src/handbook.css`; `DESIGN.md` documents their roles and `UX-CONTRACT.md` documents navigation, focus, state, and recovery behavior. Existing chapter topology CSS is scoped and adapted rather than globally loading the old page shell. Semantic document HTML is a deliberate compatibility variant for technical figures and the original interactive experiments.

Verification reports and screenshots are in `evidence/`. `full-sweep.json` covers all nine chapters at 390, 1440 and 1728; `full-interactions.json` records navigation, search, bookmarks, theme/locale, labs and failure recovery; `full-a11y.json` records automated accessibility evidence. Static Premium audit is preserved separately and reviewed for unused registry examples and `Button asChild` false positives; do not interpret its raw errors as a runtime test result. Better Design MCP was unavailable in this continuation, so its new live review receipt is not claimed.
