# Archify workflow sources

`skills-zh.json`, `skills-en.json` and `memory-zh.json` are frozen showcase specifications. Their standalone HTML lives in `../public/diagrams/`. Use Archify `deliver`, never direct edits to the HTML. PNG/SVG previews were exported through those exact viewers. Native dark/light PNGs are used by the reader, while the full viewer opens in a new tab.

`memory-en.json` is an undelivered draft. Its desktop readability diagnostic did not improve after two focused repairs. No English Memory HTML was published. The English reader labels its Chinese diagram fallback explicitly.

Delivery hashes, 9/9 artifact validation, independent automated desktop containment evidence and image-capable visual review are recorded separately in `../evidence/archify/handoff.json`. Validation and HTML/specification/published-copy hash equality were checked again at handoff.
